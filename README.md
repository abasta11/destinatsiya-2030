# Дестинация 2030

Онлайн-стратегия для школьников, изучающих туризм: развитие туризма в Калининградской области с 2026 по 2030 год.

- `host.html` — пульт ведущего: QR-код, карта нагрузки на зоны, проекты, совет дестинации, итоги года, финальный доклад.
- `play.html` — экран команды на телефоне: роль и секретная цель, регион, проекты, сделки, голосование.
- `js/game.js` — данные (зоны, роли, проекты, события, цели) и модель расчёта года.

Ориентиры: турпоток области около 2,2 млн (2024) и 2,3–2,5 млн (2025) по оценкам властей; потолок туристического налога 2% в 2026 году, 3% в 2027-м, 4% в 2028-м и 5% с 2029-го. Распределение по зонам, вместимость и пропускная способность — игровые оценки.

Связь идёт через публичный MQTT-брокер (EMQX или HiveMQ), регистрация не нужна.
